## ❓ FAQ

### What is 8 Ball Pool Black Diamond?

A pool training project focused on aiming guidelines, trajectory prediction, cushion shots and cue ball positioning.

### Does it include Long Line?

Extended aiming lines and trajectory visualization are part of the training feature layout.

### Can I practice bank shots?

The configuration includes single-cushion, double-cushion and multi-cushion practice profiles.

### Does it generate unlimited coins or cash?

No. The project focuses on shot analysis and billiard training rather than modifying account balances.

### Can I customize aiming guidelines?

The interface layout includes adjustable line length, thickness, color and opacity.
